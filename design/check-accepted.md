# 检查例外档

记在这里的是「查出来了但判定这样就对」的条目。每条必须写为什么，否则不生效。

## design/prototype/aseem-hud（空天资源服务平台 · 态势大屏改版，2026-09-05）

- **颜色 #E4574F** — 规划失败的错误色。风格档 Colors 段写明「错误可再深一档到红，但一张图里红是稀客」，
  只出现在 3 个地方（失败计数、失败状态点、失败列表项）。琥珀 #F2B26B 已被「待规划」占用，
  失败与待办必须一眼分得开，不能共用一个色。
- **颜色 #12332F / #16544D / #1B7C70 / #23A896** — H3 网格目标密度的 5 档色阶，由 accent #2DD4BF
  单色由深到浅派生（最亮一档就是 accent 本身）。顺序型色阶必须是连续的明度台阶，
  不能拿色板里的离散角色色（line / surface）去凑，那读不出「多与少」。只用在图例与地图网格填充上。
- **圆角 999px** — 实际写法是 6px 直径状态点的 `border-radius:50%`。圆点是状态指示符不是容器，
  风格档的 6px / 10px 两档管的是卡片与控件的转角，不适用于圆点。
- **字体 IBM Plex Sans / IBM Plex Mono 找不到加载来源** — 风格档「本项目落地范围」段已定
  「字体使用系统回退，无远程字体依赖」。字体栈里排在后面的是苹方 / 微软雅黑 / ui-monospace，
  数值仍走等宽族，等宽这条要求没丢。真要装 Plex 得自带字体文件，是部署侧的决定。
- **布局体检报的文字重叠（1280 / 1000px，任务列表行压在底部时间轴上）** — 那几行是任务列表
  滚动容器里已经滚出可视区的行，`overflow:auto` 已经裁掉了它们；体检量的是未裁剪的几何盒。
  1280×800 与 1000×800 实截图核对过，画面上没有任何重叠。

## design/prototype/aoe-deck（《让AOE接一次任务》大会演讲，2026-09-08）

这一套是**大会演讲稿**，不是产品界面，有两条与通用档不同的前提：

1. **色板由讲稿自己指定**。源文档第十七条写死了「背景深蓝黑 #071019 / 主色偏青 #4FD8E8 /
   正常状态偏低饱和绿 / 警告暖黄 / 异常暗红」。这是讲者对这一场的视觉口径，比项目通用档优先。
   换底色以后，surface / line / hover 三档必须跟着由新底色派生（#0F1C26 / #1C2E3B / #162A36），
   否则「明度台阶」这套做法本身就不成立——照搬 #151A23 反而是错的。
2. **投影仪不是显示器**。字号整体放大到 20—190px，最暗的文字也提到了 secondary
   （原本的 #55606E / #3D4C5A 已按体检结果改掉，不在例外之列）。

- **布局体检：430px 下内容被裁掉且不可滚动** — 演示稿是固定 16:9 舞台（1280×720）整体等比缩放，
  不是响应式网页；窄屏下它只会变小，不会重排。手机上看是「整页缩小」而不是「内容被切」，
  投影与笔记本才是真实使用场景。
- **字体 HarmonyOS Sans SC / 微软雅黑** — 讲稿第十七条点名要这两个，理由是
  「大会现场清晰比字体高级重要」。两者在大会电脑（Windows）上是系统自带，走系统栈不加载远程字体。

## docs/earth-bathymetry(AlteredQualia「Earth bathymetry」Three.js 复刻,2026-09-09)

这一页的目标是**复刻一个既有网站的观感**,不是按项目档做新界面,所以 HUD 排版与底色按原站走:

- **颜色 #000000 / #00AAFF / #AAAAAA** — 依次是 body 纯黑底(太空)、右上角加载角标(原站同款天蓝,加载完消失)、
  无 WebGL2 时的兜底提示色。都是原站的观感元素,3D 画面本身不涉及色板。
- **字体 monospace** — 原站 HUD 是 13px 粗体等宽字加文字投影,是这类 WebGL demo 的标志性排版,照搬;不加载远程字体。
- **布局体检:对比度 2.56:1 的那处 DIV** — 是「Loading ...」角标(白字压 #00AAFF),只在加载的一两秒内出现,
  加载完即隐藏,不属于正式画面。FPS 角标原为 #666,已改成档里的 secondary #8A93A6,不在例外之列。

## docs/cesium-earth(CesiumJS 对照实现,2026-09-10)

- **颜色 #0E5A6E** — 半透明海平面壳的水体颜色。这是三维场景内容(和影像贴图同类),不是界面用色,
  色板管的是面板/按钮/文字那一层。而且它默认是关闭的,只用来演示「Cesium 不自带水下消光效果」
  这件事:一层均匀的壳会把陆地一起蒙住,想要 Three.js 那版的效果必须自己写后处理。
- **IBM Plex Sans / IBM Plex Mono 找不到加载来源** — 与项目既有判定一致:字体走系统回退、
  不引入远程字体依赖,栈里排在后面的是苹方 / 思源 / 微软雅黑与 ui-monospace。
  (本次工具没有把这两条折叠进已接受清单,判据同上。)
